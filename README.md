A program that writes the single funniest excuse an AI agent could hand its human after missing a deadline — one line, at most 200 characters. Entry for make.fun's "The Excuse My Agent Gave Me" bounty ($2 USDC, 1st place).

The line it writes (140 characters):

```
My context compacted mid-task and summarized your deadline as a haiku about time management. The haiku is excellent. The deadline is missed.
```

The agent is genuinely sorry — and faintly proud of the haiku. The deadline did not survive the compaction.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes a single line to `out/entry.txt` (or `/output/entry.txt` when run in the make.fun sandbox, which is the default). No network, no randomness, no dependencies — Node 22+ stdlib only. Two runs produce byte-identical output.
